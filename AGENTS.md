# Repository instructions

## Rules

- Use Bun for JavaScript and TypeScript package and script commands.
- Use `workspace:*` for internal dependencies and the root catalog for shared versions.
- Regenerate `bun.lock` with Bun.
- Never read or print `.env` contents. Keep secrets out of source and tool output.
- When adding an app or package, create its `AGENTS.md` with its responsibility, structure, commands, and local rules. Do not repeat root instructions.
- Use tabs, single quotes, and no trailing commas in JavaScript and TypeScript.

## Commands

See `README.md` for setup and root commands.
