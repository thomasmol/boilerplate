# Database

Shared PostgreSQL data access using Drizzle and Bun SQL.

## Structure

- `index.ts`: database connection and public exports
- `schema.ts`: tables and indexes
- `relations.ts`: relational query definitions
- `drizzle.config.ts`: migration and Studio configuration
- `migrations`: generated migrations, when present

## Rules

- Keep shared schema, relations, and database access in this package.
- Update relation definitions when changing related tables.
- Keep migration files generated by Drizzle Kit. Do not edit generated files manually.
- Generate migrations only when requested. Applying migrations requires explicit approval.

## Local services

Start PostgreSQL and Redis with `bun run infra` from the repository root. Both services bind to localhost and use persistent volumes.

| Variable | Local connection |
| --- | --- |
| `DATABASE_URL` | `postgresql://postgres:postgres@127.0.0.1:5432/app` |
| `REDIS_URL` | `redis://127.0.0.1:6379` |

These credentials are for local development only.

Create the database tables:

```sh
bun run db:generate
bun run db:migrate
```

Stop containers without deleting their data with `bun run infra:down`.

## Commands

From the repository root:

- `bun run db:generate`: generate migrations
- `bun run db:migrate`: apply migrations
- `bun run db:studio`: open Studio
- `bun run check`: include this package in type checks
